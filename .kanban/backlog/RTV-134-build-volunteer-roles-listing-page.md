## Summary

Create a dedicated page where volunteers can see the roles they can help with. Page layout should be ready to accept role descriptions (from partners or internally) without requiring them at launch.

## Problem Or Opportunity

Volunteers who are ready to act have no dedicated place to discover the roles they can fill. This friction discourages engagement.

## Scope

R1: Roles page is discoverable from home page (e.g., linked from the CTA or main navigation)
R2: Page displays a placeholder or empty state that explains what role information will go there
R3: Page layout and styling accommodate role cards/descriptions (title, summary, time commitment, contact info)
R4: Navigation back to home page is clear
R5: Mobile and desktop layouts are clean and usable

## Proposed Design / Approach

Build the page structure and styling to match the site design; include placeholder role cards or a message inviting partners to contribute role data. Deferred: integrate actual role data in a later discovery task.

## Verification Plan

- R1: Home page CTA links to the roles page, and main navigation includes a Roles link
- R2: Roles page displays a clear message or placeholder indicating where role descriptions will appear
- R3: Page layout accommodates role cards with fields for title, summary, time, and contact
- R4: A back-to-home link or navigation breadcrumb is visible
- R5: Roles page renders correctly on mobile and desktop viewports
