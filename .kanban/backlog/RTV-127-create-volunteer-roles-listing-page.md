## Summary

Build a dedicated page listing 2–4 available volunteer roles with brief descriptions and a path for volunteers to get involved.

## Problem Or Opportunity

Volunteers land on the site but have no clear view of what roles are available or how to contribute.

## Scope

R1: Create a /roles or /volunteer route/page. R2: List 2–4 roles with title, brief description (1–2 sentences), and key responsibilities. R3: Ensure consistent styling with the home page. R4: Include a call-to-action (e.g., "I want to help" or "Learn more"). R5: Make the page discoverable from the home page via the link added in Stage 1. R6: Design for future partner data source (but start with hardcoded content for MVP).

## Proposed Design / Approach

1. Define 2–4 volunteer roles and descriptions (owner input). 2. Sketch page layout and information hierarchy. 3. Build the page template/component. 4. Seed with hardcoded role data for MVP. 5. Architect to accept structured role data later (deferred to Stage 3).

## Verification Plan

1. Roles page is accessible at a public URL (/roles or /volunteer). 2. Page displays 2–4 roles with title and description for each role. 3. Page is linked from home page (from Stage 1 copy). 4. Page meets accessibility standards (WCAG AA contrast, screen reader). 5. Page styling is consistent with site design system. 6. Call-to-action button/link is functional.
